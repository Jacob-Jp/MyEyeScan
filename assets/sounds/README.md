# Audio Assets

## Required Sound File

Place an **ambulance.mp3** file in this directory for critical drowsiness alerts.

### Requirements:
- **Filename**: `ambulance.mp3`
- **Format**: MP3
- **Type**: Emergency siren or ambulance sound
- **Duration**: 2-5 seconds (will loop automatically)
- **Volume**: Loud enough to alert driver

### Where to find:
You can download free siren sounds from:
- https://pixabay.com/sound-effects/search/ambulance/
- https://freesound.org/search/?q=ambulance+siren
- https://www.zapsplat.com/sound-effect-category/sirens-and-alarms/

### Usage:
The sound plays automatically when drowsiness level reaches **70% or higher** and stops when it drops below 70%.
